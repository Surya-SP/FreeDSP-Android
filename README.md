# FreeDSP Android

Tune your Moondrop FreeDSP cable from your Android phone: drag bands on the response graph, save profiles, bring in AutoEQ or squig.link EQs, and write them to the cable, checked by reading them back.

- **Cable:** original FreeDSP (`35D8:1496`). Not the FreeDSP Mini.
- **Access:** needs USB host. No root, no internet permission, no microphone.
- **Credit:** protocol and filter maths after [FreeDSP-Studio](https://github.com/EffectiveEquivalent/FreeDSP-Studio) (MIT). See `docs/KNOWLEDGE.md` for what is proven and how.
